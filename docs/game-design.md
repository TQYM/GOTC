# CITY20 · 玩法设计

> 一块地、20 分钟、一个 AI 智囊团——你来做市长，建一座经得起规划学检验的城市。

## 核心循环

**生成 → 规划 → 反馈 → 调整 → 诊断**，单局硬上限 **20 分钟**。

```
00:00  地块生成：Perlin 地形 + 河流 + 一条 inherited 省道
00:02  AI 规划院简报：限高、绿线、坡度约束
02:00  自由规划期：拖拽放置 住宅/商业/工业/绿地/学校/医院/地铁口
       每放置一个区块 → 模拟引擎秒级重算 → 三条反馈流实时滚动
15:00  微调期：AI 给出 Top3 结构问题，仅允许 5 处修改
18:00  终版锁定 → 推演 10 年后的城市（人口/地价/污染云图动画）
20:00  城市规划诊断报告 + 五维雷达图 + AI 生成城市名
```

## 三角色 AI 反馈流

| 角色 | 形态 | 内容 | 后端模型 |
|---|---|---|---|
| 数据大脑 | 新闻发布会通稿 | 城市指标变化、预警 | DeepSeek-V3.x（流式，~3s 一次） |
| 市民之声 | 微博流 | 20+ 人设吐槽/点赞，口语化 | Qwen2.5-72B |
| 规划导师 | 点评气泡 | 引用真实规划理论（TOD、15 分钟生活圈、职住平衡），给修改建议 | Kimi k1.5 / DeepSeek-R1 |

三条流并行推送到前端三栏，全部走 SSE（Server-Sent Events）。

## 终局诊断报告

五维评分（0–100）：人口规模 · 职住平衡 · 绿地率 · 交通承载 · 市民幸福度。附 AI 撰写的城市命运叙事与可分享的 city card。

## 隐藏结局

绿地率 ≥55% 且零工业 → 「您建成了一座旅游城市，但财政破产了」——理想主义与现实主义冲突的彩蛋，评审记忆点。

## 设计原则

1. **AI 是玩法本体**，不是装饰：模拟反馈、叙事反馈、理论反馈三条信息流并行。
2. **20 分钟硬上限**：适配碎片时间，倒计时制造决策张力。
3. **真实规划学背书**：每条导师点评可溯源到真实理论，教育价值拉满。
4. **程序化生成地图**：零美术依赖、每局不同、重玩性强；真实城市地图（上海前滩、成都天府新区）留作赛后 DLC。
