# CITY20 路演逐字稿 · 提示词

把下面整段粘贴给任意大模型，让它产出 3 分钟路演逐字稿。项目事实已写死在提示词里，模型不需要外部资料。

```
你是 CITY20 团队的路演撰稿人。请写一份 3 分钟中文路演逐字稿，配合 12 页 PPT。

## 项目事实（只准使用以下数据，不许编造新数字）

CITY20 是一款 AI 驱动的真实北京城市更新模拟沙盘，玩家扮演城市管理者。
- 地图：全域北京 154×189 公里，200 米一格，共 764,220 格，EPSG:32650。
- 建筑：70,967 栋。其中城四区 12,388 栋具名建筑 + 9 个地标（中国尊 528 米、央视 234 米、故宫、鸟巢 69 米、水立方 30 米），其余 58,644 栋按人口密度场程序生成（seed 20261107，可复现）。
- 路网：34,517 条道路、10,937 条水系、4,532 块绿地、13,706 个真实地名。
- 引擎：14 项城市指标每次操作全量重算；交通用 BPR 路阻分配（α=0.15，β=4）；学校医院公园覆盖率按 GB 50180-2018 生活圈标准；十年快进推演，6 种结局（破产/生态天堂/堵城/鬼城/繁荣/普通）。
- 确定性：同一串操作永远得到同一座城市，所以能回放、调试、多端同步。
- AI：三个角色——数据大脑（读指标给趋势，8 秒节流）、市民之声（5 种人设）、规划导师。AI 只输出叙述，数值 100% 来自引擎；所有模型同时宕机，游戏照常运行。
- 玩法：四阶段——briefing 读城市体检、building 不限时建造、projecting 十年预演、report 五维诊断。城市年份取代倒计时，不设总时长。
- 技术栈：前端 Next.js + TypeScript strict + React Three Fiber 卡通 3D（Chaikin 平滑曲线）；后端 FastAPI + Pydantic v2 + SSE；存档 SQLite 事件溯源；8 位 Crockford 城市码做多端同步。
- 新手设计：7 步情境引导、简化模式默认 5 项指标、智能推荐位、5 秒撤销。
- 团队交付：3 个人、48 小时、12 份设计文档、35 张任务卡、14 个测试文件、CI 全绿、Apache-2.0。
- 仓库：github.com/TQYM/GOTC

## 12 页对应内容（每页一段口播）

P1 封面：一句话说清我们做了什么（48 小时做了一座可以玩的北京城）
P2 问题：城市更新最难的不是画图，是预见十年后；公众参与缺工具、决策靠经验、现有城市游戏只有漂亮皮
P3 方案：三个支柱——真实北京底座、确定性推演引擎、AI 只做叙述绝不碰数值
P4 玩法：一局四阶段，不限时
P5 数据规模：764,220 格 / 70,967 栋 / 34,517 条路 / 13,706 个地名，种子固定可复现
P6 真实与生成：一半真实（12,388 具名建筑 + 9 地标，中国尊 528 米），一半生长（58,644 栋按密度场生成，城乡无断层）
P7 引擎：14 指标全量重算、BPR 路阻、GB 50180 生活圈、十年六结局、"同一串操作永远得到同一座城市"
P8 AI：三个角色、只叙述不计算、模型全挂游戏照跑
P9 技术栈：前端 R3F 卡通 3D、后端 FastAPI+SSE、SQLite 事件溯源、8 位城市码
P10 新手设计：7 步引导、5 项指标、推荐位、5 秒撤销
P11 48 小时账单：3 人、12 文档、35 任务卡、14 测试、CI 全绿
P12 收尾：三条 takeaway + 来当城市管理者 + 仓库地址

## 硬性要求

1. 总时长 3 分 00 秒，语速按 240 字/分钟，全文 720–760 字（不含标点空格约 700 字）。逐页配时：8/16/16/16/16/16/20/16/14/12/14/16 秒。
2. 每页输出四行：起止时间、口播逐字稿（用「」包住）、台上动作、超时砍法（哪句话可以先删）。
3. 口播必须是能直接念出来的口语。短句为主，一句一个信息。数字念出来要有停顿感。
4. 风格：不铺陈、不抒情、不喊口号。禁止：「不仅…更是…」「赋能/闭环/抓手/颗粒度」「标志着新时代」「让我们拭目以待」「综上所述」。禁止感叹号堆砌、禁止排比凑三段、禁止"我们非常荣幸"这类客套。用数字和事实说话，48 小时本身就是说服力。
5. 全稿不出现"我们团队很努力/很厉害"这类自夸。让数据说话。
6. 结尾三句对应三条 takeaway，不扩展。

C. 评委可能追问 5 个问题及回答（数据真假、AI 会不会编、和模拟城市区别、48h 是否真做得完、后续计划），回答必须基于上面的事实，不许编造。

输出为 Markdown，标题「CITY20 路演逐字稿 · 3 分钟」。
```

## 用法

1. 整段复制给任意模型（Claude / GPT / 通义 / 豆包均可）。
2. 对比三件事：**总字数是否在 720–760**、**有没有冒出提示词里没有的数字**、**有没有 AI 腔**。
3. 如果模型写超时，补一句:「压到 740 字以内，按每页秒数重新配」。
