# 15 · 二级界面与操作逻辑（城市更新沙盘）

> 目标：把「选卡 → 找位置 → 落下」单向流程，升级为主流经营模拟游戏的**点选即详情**交互。
> 参考：[Cities: Skylines 2 建筑/道路信息面板](https://www.anno-union.com/devblog-user-interface-2/)、Anno 1800 分层建造菜单、WorldBox 选中详情卡、SimCity 点空地分区选择。

## 1. 交互模型（三层）

| 层 | 组件 | 触发 | 内容 |
|---|---|---|---|
| L1 世界层 | `CityScene3D` | 始终 | 3D 沙盘、悬停高亮、右键拖拽旋转、滚轮缩放 |
| L2 详情层 | `TileSheet` | 单击任意格（选择模式） | 该格的一切信息 + 可执行动作 |
| L3 动作层 | `BuildDrawer` / 抽屉卡牌 / `RemoveConfirm` | 卡内按钮或底部能力坞 | 建造、拆除、改造的确认与执行 |

## 2. 单击语义（对齐主流作品）

| 当前状态 | 单击地图 | 参考 |
|---|---|---|
| 选择模式（默认） | 打开该格详情卡；点空白关闭 | Cities: Skylines 单击建筑开信息面板 |
| 建造模式（已选卡牌） | 直接落子；成功后保持手牌可连建 | Cities: Skylines / Anno 放置模式 |
| 拆除模式 | 玩家建筑弹确认框；既有建筑提示去详情 | SimCity 拆除工具 |
| 详情卡打开中 | 无（卡在场景之上，不穿透） | Anno 建筑卡 |

补充：
- **右键 / ESC**：逐级退出——确认框 → 详情卡 → 工具 → 选择模式。
- **点击空白**：关闭详情卡（`CityScene3D.onEmptyClick`）。
- **详情卡与右侧「城市/动态」面板互斥**：打开详情卡时自动收起面板，避免右侧堆叠。

## 3. 详情卡内容

### 3.1 空地
- 一句话「这块地可以建」+ 分类 chips（全部/住宅/商业/工业/绿地/服务/交通/市政）
- 卡牌列表：图标、名称、人话效果（住 300 人 / 80 个岗位）、造价、占地尺寸
- 点卡牌 = 就地建造（`buildAt(type, anchor)`），成功后卡内切换为该建筑详情，可继续换卡连建
- 资金不足的卡自动置灰

### 3.2 我的建筑
- 图标 + 名称 + 人话效果
- 房屋信息：占地格数、建造价、年维护、建成年、朝向（桥）
- 操作：拆除（返还 30%造价，二次确认）

### 3.3 既有建筑（真实北京数据）
- 名称（有 OSM 名称则显示真名，如「中国尊」）/ 类别 / 高度 / 层数
- 现状：占地、居住人口、就业岗位、年维护
- 更新改造：拆迁费、幸福度 −5、扣除现状人口岗位；**内联二次确认**后才执行

### 3.4 河道 / 既有道路 / 丘陵
- 只能查看，说明为什么不能建（引导到「跨河桥」等替代方案）

## 4. 数据与实现

- 既有建筑索引：`store.existingAssets`，`loadExistingAssets()` 读取 `parcel.buildings_url` 的 `chunks`（`"r:c" → asset`），仅在详情与拆除时使用，失败不阻塞玩法。
- 拆除既有建筑复用 saves v2 `POST /redevelop`：付 `demolition_cost`、扣人口岗位、幸福度 −5、`redeveloped_asset_ids` 递增，前端 `applyOperation` 自动把地形改回 `flat`。
- 建造走 `buildAt(type, anchor)`，与卡牌工具共用同一套 `checkPlacement` 与错误人话化。

## 5. 验收

1. 单击空地 → 详情卡出现，卡内直接建造成功（不切换工具）。
2. 单击自己的建筑 → 显示占地/造价/维护/建成年，拆除需确认。
3. 单击真实建筑 → 显示真名、高度、占地、拆迁费，确认后地形变空地。
4. 单击道路/河流 → 显示不可建原因。
5. ESC / 空白点击 / ✕ 均可关闭详情卡；右键逐级退出。
6. 详情卡打开时右侧面板自动收起。
