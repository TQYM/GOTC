# 14 · 新手引导与操作门槛优化

> m00842 决策：增加新手引导，系统性降低操作门槛。原则：**边玩边学，绝不拦路**——引导是情境式提示而非强制教程，任何一步可跳过；门槛优化覆盖「看不懂、不敢点、怕点错」三类阻力。

## 1. 新手引导（Onboarding）

### 1.1 结构

- **欢迎三屏**（可一键跳过）：① 你是城市管理者；② 这是真实北京（CBD–通惠河），熟悉的街区由你更新；③ 不限时，慢慢建，随时看未来。
- **情境式引导局**：首次进入游戏自动开启，7 步，每步 = 高亮一个 UI 元素 + 一句话 + 一个完成条件（玩家真实操作即完成，无「下一步」按钮）。
- 每步右上角「跳过引导」；设置页可「重新体验引导」；引导完成状态存本地并存入存档（换端不重复弹）。

### 1.2 引导脚本（7 步）

| 步 | 高亮目标 | 一句话文案 | 完成条件 |
|---|---|---|---|
| 1 认识城市 | 3D 场景 | 「这里是国贸。滚轮放大，找找中国尊。」 | 缩放一次 |
| 2 城市脉搏 | 指标面板 | 「人口、资金、幸福度——你城市的生命体征都在这。」 | 点开指标面板 |
| 3 第一个家 | 底部住宅卡 | 「居民需要家。点这张卡，放到绿色预览的空地上。」 | 成功放置一块住宅 |
| 4 第一份工作 | 商业/工业卡 | 「人住下了，还得有工作。放一块商店试试。」 | 成功放置一块商业或工业 |
| 5 市民在说话 | 右侧信息流 | 「你的每个决策，市民都有话说。听听。」 | 点击一条 AI 消息 |
| 6 看见未来 | 「快进一年」按钮 | 「点一下，城市过一年——税收、人口、变化都会来。」 | advance 一次 |
| 7 第一次体检 | 「生成报告」按钮 | 「随时生成体检报告，规划导师告诉你城市哪里好、哪里病。」 | 生成一份报告 |

完成后弹出「你已经是城市管理者了」+ 三个自由目标建议（让通勤 <30 分钟 / 绿地率 ≥30% / 财政扭亏），引导结束。

### 1.3 情境提示（引导结束后仍生效，每类只弹一次）

- 首次资金不足：高亮资金指标 +「钱不够了——快进一年收税，或拆建筑收回 30%」。
- 首次非法放置：红框旁一句话说明具体原因（「河道上不能建，桥才行」「这块是既有建筑，先拆迁」）。
- 首次进入拆迁模式：「拆迁要付成本、居民会不满，确认前可以先点建筑看详情」。
- 首次连续 3 块住宅无商业：导师轻提示（见 [04](04-ai-roles.md) 新手期频率加密）。

## 2. 降低操作门槛

### 2.1 看不懂 → 人话化与简化模式

- **指标简化模式（默认）**：只显示 5 个核心指标——人口 / 资金 / 幸福度 / 通勤 / 绿地率；「专业模式」开关切到全部 14 个。简化模式下每个指标带一句人话注解（如 avg_commute →「平均通勤，越短越好」）。
- **区块卡牌人话化**：卡面写「低层住宅 · 住 300 人 · 6 万」而非字段名；造价、维护、产出、占地直接可读；长按/悬停出详细参数。
- **错误提示人话化**：错误码统一映射为「一句人话 + 怎么办」，不再裸弹 invalid_placement（映射表归前端文案文件，02 错误码不变）。

### 2.2 不敢点 → 推荐位与一键补齐

- **推荐位置**：选中区块卡后，「推荐位置」按钮调后端推荐端点（§3），返回至多 3 个推荐格及理由（邻路 / 服务缺口 / 地价低），场景中亮出 1/2/3 序号标记，点其一即落子。
- **一键补齐**：指标面板发现服务缺口时（如教育覆盖 <60%）显示提示条「这片孩子没学上」→ 点击直接进入学校放置模式并自动圈出推荐格。
- **开局即最佳视角**：默认鸟瞰角已调好，不调镜头也能完成全部核心操作。

### 2.3 怕点错 → 撤销与预览

- **5 秒撤销**：放置成功后 toast 带「撤销」按钮（5 秒窗口），等同全额返还撤回；后端记 undo 操作并广播（§3）。拆除/拆迁不在撤销范围（仍有二次确认）。
- **放置前全预览**：幽灵预览除合法性红绿外，还显示预计指标变化方向（人口↑ 资金↓ 的简箭头，来自 place 的预校验响应或本地按目录静态估算，仅体验层）。
- **触控目标 ≥64px**：工具栏卡牌、按钮统一放大触控区（对齐 [09](09-cross-platform.md)）。

### 2.4 AI 导师新手期加密

- 新手期（前 20 次操作）导师点评频率从每 10 次加密到每 5 次，文案侧重「下一步可以做什么」；20 次后恢复正常频率（[04](04-ai-roles.md) 同步）。

## 3. 契约增补（只增不改，v1.3）

- `GET /api/saves/{id}/recommend?block_type=TYPE` → 至多 3 个推荐格：`{cells, reason}`，reason ∈ `near_road / coverage_gap / cheap_land`。后端 sim 计算：合法且邻路优先，服务类按覆盖缺口加权，住宅按低地价加权。
- `POST /api/saves/{id}/undo` → 撤销最近一次 place：5 秒窗口内、全额返还、恢复该格地形；窗口外或最近 op 非 place 返回 400 `invalid_phase`（文案「只能撤销刚刚的放置」）。op_applied 广播保证多端一致。
- 引导状态不进契约：本地 localStorage + 存档 meta 标记即可，不占 op 序列。
