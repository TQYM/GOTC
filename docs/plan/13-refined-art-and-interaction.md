# 13 · 精致卡通美术 · 真实地名 · 特殊建筑专属页面 · 天际线式交互

> m00803 决策：卡通感 = **把真实北京做平滑曲线化**，不是大方块；要精致、要一眼认出这是什么；学校/医院等特殊建筑有专属页面；全局操作参考《城市：天际线》系列；地名与现实一致。
> 本文档修正并取代 [11 §6.0](11-real-beijing-3d.md) 中可能被误读为「体素方块化」的表述；渲染管线其余部分（分层/性能预算/数据管线）不变。

## 1. 美术方向修正：平滑曲线化，识别度优先

### 1.1 核心原则

- **卡通 = 平滑 + 提炼，不是简化成方块。** 对真实建筑轮廓做曲线平滑与细节提炼，保留识别特征；禁止一律拉伸成无特征的长方体。
- **一眼认出**：任何建筑在默认视角下 1 秒内可辨认类别；地标必须能认出「这是哪」。
- 精致感来源：平滑的轮廓曲线、檐口线与屋顶变化、柔和配色与光影、真实地名标注——而非堆砌多边形。

### 1.2 建筑轮廓处理（管线内自动完成）

| 步骤 | 处理 | 参数 |
|---|---|---|
| 轮廓平滑 | OSM 多边形做 Chaikin 角切割平滑（2 次迭代），直角变柔；识别性折角（如 L 形教学楼）保留，不做过度圆滑 | 切角比 0.25，最小保留边长 1m |
| 转角倒角 | 拉伸体的垂直棱做微倒角，柔化光影 | 半径 0.3–0.8m |
| 屋顶 | 按 OSM `roof:shape` 建模：flat→平屋顶+檐口线（顶部 1m 高收边）；gabled/hipped→简化坡屋顶；缺失时按建筑类型默认（民居坡顶、办公平顶） | 坡顶坡度 25°–35° |
| 立面 | 不做贴图纹理，用色块+分层线脚表达；高层加 2–3 条横向楼层带 | 楼层带间距按层高 |
| 高度 | 沿用 [11 §6.3](11-real-beijing-3d.md) 兜底表；地标手工高度不变 | — |

### 1.3 识别度分级（三档建模投入）

| 档位 | 对象 | 建模方式 |
|---|---|---|
| 地标级 | 中国尊、央视大楼、国贸三期、北京银泰、通惠河桥梁等 | 手工参数化特征件（轮廓+标志特征，如央视的悬挑环、中国尊的收分曲线），toon 化但特征不失真 |
| 特征级 | 学校（教学楼+操场+跑道）、医院（门诊楼+十字标识）、地铁站（站厅+标识柱）、商场（裙楼+主楼） | 类型化组件拼装：每种类型定义 1 套「识别套件」（如学校 = 坡顶教学楼 + 红色塑胶跑道操场），一眼可读 |
| 普通级 | 民居、办公、工业 | 平滑体块 + 屋顶变化 + 类别配色 + 高度变化，拒绝千篇一律 |

### 1.4 环境要素

- **河流/水系**：沿 OSM 中心线用 Catmull-Rom 样条生成平滑水面带，河岸自然弯曲（禁止折线水道）；通惠河按真实走向。
- **道路**：真实中心线平滑条带，路口倒角衔接，车道线简化为白色虚线；省道与地铁走向与现实一致。
- **植被**：球状/椭球树冠 + 短树干，2–3 种绿色随机；沿河与公园成簇分布。
- **配色与动效**：沿用 [11 §6.0](11-real-beijing-3d.md) 配色板与 ≤300ms 动效纪律。

## 2. 真实地名标注（与现实一致）

### 2.1 数据源与导出

- 全部地名取自 OSM 原始数据：`name` / `name:zh` 字段，**中文名优先**，不做任何虚构改写。
- 标注类别：水系（通惠河）、道路（建国路、东三环等）、片区/小区、学校、医院、地铁站、公园、地标。
- 数据管线新增产物 `labels.json`（随 parcel 打包，见 [11 §4](11-real-beijing-3d.md)）：每条含 `name`、`category`、`position`（经纬度转场景坐标）、`importance`（1–5，用于分级显示）、可选 `ref_building_id`（关联既有建筑）。

### 2.2 渲染规格

- 3D 场景内 Billboard 文字（troika-three-text 或 drei Html），中文无衬线（思源黑体/系统 PingFang），白色描边深色字或深色底板白字，保证卡通画面上可读。
- **LOD 分级**：全景默认只显示 `importance≥4`（地标/水系/主干道）；拉近到街区尺度显示全部；标注避让重叠，重叠时按 importance 取舍。
- 玩家新放置的建筑：沿用「类型名 + 序号」命名（如「第三小学」），与既有真实地名并置不冲突。

## 3. 特殊建筑专属页面（学校 / 医院等）

### 3.1 触发与范围

- 点击服务类建筑（学校、医院，扩展：地铁站、公园、消防/市政）→ 打开**专属详情页**（右侧滑出大面板，移动端全屏）。
- 既有真实学校/医院（OSM `amenity=school/hospital`）同样可点开：显示现状信息 + 拆迁重建入口（redevelop，见 [11 §5](11-real-beijing-3d.md)）。
- 普通住宅/商业/工业用简化信息卡（指标一行 + 拆除按钮），不做专属页。

### 3.2 页面内容规格

| 区块 | 学校页 | 医院页 |
|---|---|---|
| 头部 | 名称（真实地名或玩家命名）+ 类型徽章 + 卡通缩略图 | 同左 |
| 服务概览 | 覆盖半径 600m 内服务人口、当前容量 vs 就学需求、缺口提示 | 覆盖人口、接诊容量 vs 就诊压力、缺口提示 |
| 满意度 | 服务满意度（来自 coverage_edu 与幸福度分解） | 服务满意度（coverage_med） |
| 历史曲线 | 覆盖人口/满意度随 city_year 的折线（自绘 SVG） | 同左 |
| 周边 | 覆盖范围高亮叠加在 3D 场景上（600m 半径圈 + 服务住宅高亮） | 同左 |
| 操作 | 扩建（提高容量，造价按 sim-config）、跳转「增设同类」放置模式、拆除/拆迁 | 同左 |

- 通用约定：页面打开时镜头平滑聚焦该建筑（≤300ms）；ESC/右键返回；数据全部来自后端详情端点（§5），前端不本地推算。

## 4. 全局操作逻辑（参考《城市：天际线》系列）

### 4.1 键鼠映射

| 操作 | 键位 | 行为 |
|---|---|---|
| 点选建筑 / 放置区块 | 左键 | 选中打开信息卡或专属页；放置模式下落子 |
| 取消当前工具 / 返回 | 右键 或 ESC | 放置模式→选择模式→关闭面板，逐级退出 |
| 旋转与俯仰视角 | 右键按住拖拽 | 环绕当前视点中心 |
| 平移视角 | WASD / 方向键 / 屏幕边缘推屏（可关） | 平移速度随缩放级别自适应 |
| 缩放 | 滚轮 | 向光标位置缩放 |
| 信息视图切换 | 数字键 1–5 或左侧信息栏 | 见 §4.2 |
| 快速回到全景 | Home / 双击空白处 | 复位到默认鸟瞰 |

触屏（对齐 [09](09-cross-platform.md)）：单指点选、单指拖动平移、双指捏合缩放、双指旋转、长按建筑 = 信息卡。

### 4.2 信息视图（Info Views，天际线式覆盖层）

- 入口：左侧竖排信息栏（默认收起）。
- 五个覆盖层：**绿地与生态 / 污染分布 / 交通拥堵 / 教育覆盖 / 医疗覆盖**——开启后 3D 场景切换为对应热力着色（玩家建筑保留轮廓，其余淡化）。
- 与专属页面联动：学校/医院页打开时自动叠加对应覆盖层。

### 4.3 工具栏与建造流

- 底部工具栏按天际线式大类分页：住宅 / 商业 / 工业 / 绿地 / 公共服务 / 交通 / 市政；选中大类展开该类的区块卡牌。
- 放置模式：幽灵预览（合法绿/非法红）→ 左键落子 → 保持放置模式可连续放置（天际线手感）；右键/ESC 退出。
- 拆除模式、拆迁模式（redevelop）为独立工具，进入后光标换样式，操作需二次确认。

## 5. 契约增补（只增不改，v1.2）

- `GET /api/saves/{id}/buildings/{tileId}` → 建筑详情：类型、名称、容量、覆盖人口、服务压力、满意度、历史序列（按 city_year）、可否扩建/拆迁及造价。既有建筑带 `existing: true` 与 OSM 原始名称。
- `labels.json` 形状（§2.1）并入 parcel 数据包契约。
- 扩建操作 `POST .../buildings/{tileId}/upgrade`：参数为扩建级别，扣款并提升容量，走 op_applied 广播（多端同步见 [10](10-persistence-sync.md)）。
- 错误码沿用 02 表（资金不足 402、阶段不符 400 等），不新增。
