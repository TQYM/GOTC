# 01 · 领域模型

> 游戏世界的"物理定律"。前后端共用的词汇表，任何文档/代码分歧以本文件为准。
> 本文件只描述**是什么**，怎么算是后端的事（见 [03](03-sim-engine.md)），怎么显示是前端的事（见 [05](05-frontend.md)）。
> ⚠️ **变更**：地块默认来自真实北京片区（GIS 栅格化），地形新增 `occupied`（既有建筑），新增 `redevelop` 更新操作，随机生成降级为沙盒模式——见 [11](11-real-beijing-3d.md)；不限时/存档/多端同步/玩家=城市管理者见 [10](10-persistence-sync.md)。

## 1. 世界几何

| 概念 | 定义 | 值 |
|---|---|---|
| 网格 Grid | 方形棋盘 | 48 × 48 格 |
| 格尺寸 CellSize | 每格边长 | 50 m（城区总面积 5.76 km²，近似一个十五分钟生活圈） |
| 坐标 | 行 r（北→南，0 起）、列 c（西→东，0 起） | 原点在西北角 |
| 地块 Parcel | 一局游戏的完整世界 | 每局随机生成一次，生成后地形不可变 |
| 区块 Tile | 玩家放置在格子上的功能单位 | 占地 1 格或多格 |

尺度依据：GB50180-2018 十五分钟生活圈居住区 5–10 万人、约 3 km² 量级；48×48 格恰好一个"可以放 40–70 个区块"的棋盘，20 分钟内决策密度合适。

## 2. 地形

每格一个地形值，生成时确定，整局不可变。**取值集合**：

| 值 | 名称 | 可建设 | 特殊规则 |
|---|---|---|---|
| flat | 平原 | 是 | 无 |
| hill | 丘陵 | 是 | 造价 ×1.5；其上住宅幸福度 −5 |
| river | 河道 | 否 | 跨河唯一方式是桥区块；地形本身不可更改 |
| bank | 河岸 | 条件 | 河流两侧各 1 格；只允许放绿地类区块或桥区块；地价 +10% |
| forest | 林地 | 否 | 保留为不可建设自然地形；不计入建设区块绿地率 |
| road_inherited | 既有省道 | 否（默认） | 生成时斜穿地块；本身算道路参与交通计算，不可拆除 |

生成比例目标（后端可调参数，见 03 §8）：河道 3–5%、河岸 6–9%、丘陵 8–12%、林地 5–8%，可建设率 ≥70%。

## 3. 区块目录

14 种区块、7 大类。数值语义见 [03](03-sim-engine.md)，此处只定身份与占地：

| id | 名称 | 大类 | 占地 | 造价（元） | 备注 |
|---|---|---|---|---|---|
| res_low | 低层住宅 | 住宅 | 1×1 | 80,000 | 容量小、幸福度基线高 |
| res_mid | 多层住宅 | 住宅 | 1×1 | 220,000 | 主力产品 |
| res_high | 高层住宅 | 住宅 | 1×1 | 600,000 | 容量大、对拥堵敏感 |
| com_shop | 社区商业 | 商业 | 1×1 | 300,000 | 服务周边住宅 |
| com_cbd | 商务中心 | 商业 | 2×2 | 2,200,000 | 大量就业岗位、地价引擎 |
| ind_light | 轻工业 | 工业 | 2×2 | 1,500,000 | 岗位多、轻度污染 |
| ind_heavy | 重工业 | 工业 | 3×3 | 4,000,000 | 岗位最多、重污染 |
| green_park | 公园绿地 | 绿地 | 1×1 | 150,000 | 幸福度核心来源 |
| green_plaza | 城市广场 | 绿地 | 2×2 | 500,000 | 地标，地价加成半径大 |
| edu_school | 学校 | 公共服务 | 2×2 | 1,200,000 | 影响教育覆盖率 |
| med_clinic | 医院 | 公共服务 | 2×2 | 2,000,000 | 影响医疗覆盖率 |
| trans_metro | 地铁站 | 交通 | 1×1 | 3,000,000 | 通勤时间大幅优化 |
| trans_road | 城市道路 | 交通 | 1×1 | 60,000 | 玩家补路网用 |
| util_bridge | 跨河桥 | 市政 | 1×N | 200,000/格 | 方向由 `orientation` 指定；跨越河道并连接两侧河岸，N 含两端河岸格 |

放置规则：
- 每格最多一个玩家区块；同格重复放置返回 `cell_occupied`。桥区块是唯一可覆盖 `river` 地形的区块，也可覆盖它两端的 `bank` 格。
- 常规多格区块以**左上格为锚点**，覆盖的所有格必须满足地形与空地要求；桥以西侧或北侧河岸格为锚点，按 `orientation` 沿直线跨至对岸河岸。任一覆盖格不满足规则则整个放置失败。
- 造价按覆盖格数 × 单价计；落在丘陵的覆盖格按 ×1.5 计。
- `util_bridge` 只允许水平或垂直直线跨越连续河道，必须至少覆盖一格河道且两端均为河岸；桥覆盖格数包括两端河岸，整段作为道路参与交通计算。

## 4. 指标（Metrics）

每局维护的 14 项指标。字段名是**前后端契约**，任何人不得单方面改名；语义变更必须双方同意并同步改本文档与 [02](02-data-contract.md)。

| 字段 | 类型 | 含义 |
|---|---|---|
| funds | 整数（元） | 财政资金，可为负；负且现金流断裂触发破产结局 |
| population | 整数（人） | 常住人口 |
| jobs | 整数（个） | 就业岗位 |
| job_res_ratio | 小数 | 职住比 = 岗位 ÷ 人口；人口为 0 时记为 0；1.0 完美，>1 岗位过剩，<1 睡城 |
| land_price_index | 小数 | 全城加权地价指数，开局 = 100 |
| green_ratio | 0–1 小数 | 玩家放置区块中绿地格数占所有已放置区块格数的比例；空城为 0。是玩法平衡指标，不等同于法定用地绿地率 |
| avg_commute | 整数（分钟） | 全城加权平均通勤时间 |
| congestion | 0–1+ 小数 | 路网饱和度，>0.9 为严重拥堵 |
| pollution | 0–1 小数 | 污染指数 |
| happiness | 0–100 整数 | 市民幸福度 |
| tax_income | 整数（元/年） | 年税收 |
| upkeep | 整数（元/年） | 年维护费 |
| coverage_edu | 0–1 小数 | 教育设施 15 分钟步行覆盖率 |
| coverage_med | 0–1 小数 | 医疗设施 15 分钟步行覆盖率 |

## 5. 游戏阶段（Phase）

| 阶段值 | 名称 | 现实时长 | 行为 |
|---|---|---|---|
| briefing | 开局简报 | 20 秒，玩家可提前跳过 | 展示地块约束；到时或调用 `advance` 后自动进入 build |
| build | 建设期 | 15 分钟 | 自由放置/拆除；游戏内 3 年，每年末结算人口与财政；到时自动进入 polish |
| polish | 微调期 | 2 分钟 | AI 给出 Top3 结构问题；不限次数、不限类型自由调整；玩家可调用 `finalize` 提前锁定，到时也自动锁定 |
| locked | 终局推演 | 约 35 秒 | 锁定操作；后端先预计算 10 年推演，再按每年约 3.5 秒广播切片；完成后进入 report |
| report | 报告展示 | 不限 | 五维评分 + 雷达图 + 结局叙事 + 重开按钮 |

**时间权威在后端**：所有阶段切换由后端广播（见 02 SSE phase_change），前端只做倒计时显示，不做本地计时决策。

## 6. 事件流（内部概念）

后端内部的三个流转环节（前端不需要关心，仅供后端模块划分参考）：

| 环节 | 输入 → 输出 |
|---|---|
| 操作事件 | 前端 REST 操作 → 会话状态变更（放置/拆除） |
| 重算事件 | 状态变更 → sim 引擎全量重算 → 新旧指标 diff |
| 触发事件 | diff 命中触发规则 → 决定调用哪个 AI 角色；AI 产出的文本走 SSE 推送 |

## 7. 结局（Ending）

终局判定，**优先级从高到低**，首个命中即定：

| 结局值 | 名称 | 判定条件 |
|---|---|---|
| bankrupt | 财政破产 | 推演 10 年内任一年 funds < 0 且税收 < 维护费 × 0.8 |
| eco_paradise | 生态乌托邦（隐藏） | 第 13 年（推演第 10 年）绿地率 ≥55%、工业区块数为 0 且人口 ≥5,000 |
| gridlock | 拥堵之城 | 平均通勤 >75 分钟且拥堵 >0.9 |
| ghost_town | 鬼城 | 人口 < 规划总容量的 20% |
| thriving | 明日之城 | 幸福度 ≥70 且职住比 ∈ [0.85, 1.15] 且拥堵 <0.6 |
| ordinary | 平凡之城 | 兜底 |

除 bankrupt（推演期任一年命中）外，结局条件均使用第 13 年（推演第 10 年）快照；鬼城只在规划住宅容量大于 0 时判定。结局只影响报告叙事文案，不影响五维评分本身（评分客观、叙事主观）。
